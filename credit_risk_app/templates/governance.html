Assumptions & Limitations

  • Source data is an explicitly synthetic/case-study dataset (see the data dictionary's own framing), not live production data — treat all figures as illustrative of methodology, not a real portfolio.
  • The model is trained with balanced class weights to handle the ~9.6% base rate; raw predicted probabilities are ranking-optimized, not calibrated to real-world likelihood (see Baseline Model page) — use percentile rank or decile, not the raw percentage, for absolute risk statements.
  • Portfolio Scenario Simulator shocks are simplified (they update the shocked field and its direct 3-month rolling counterpart only, not a full account rebuild).
  • No demographic/protected-class fields were available in this mart to test for disparate impact; a production deployment would need that analysis before use in any customer-facing decision.
  • Recommended use is an early-warning prioritization signal for collections outreach, not an autonomous credit or account-action decision.
